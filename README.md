# react-scrollto

Exercício em React e Vite de navegação com rolagem entre seções da página.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Interface em `src/App.jsx`.

**Tecnologias:** `CSS`, `HTML`, `JavaScript`, `React`, `Vite`.

## Executar localmente

```bash
npm install
npm run dev
```
